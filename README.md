# HTML Minicar-Website
==========================================================
## Beschreibung

Dieses Projekt wurde im Rahmen des Moduls 293 entwickelt und dient dazu, eine erste eigene Benutzeroberfläche (UI) mit HTML zu erstellen.

Die Website beschäftigt sich mit verschiedenen Minicars und stellt Informationen zu den jeweiligen Fahrzeugen übersichtlich dar.

Ziel des Projekts ist es, die Grundlagen von HTML sowie den Aufbau und die Gestaltung einer einfachen Website praktisch anzuwenden.
================================================
## Zweck des Projekts

Der Zweck ist die Bereitstellung von Informationen zu den verschiedenen Autos und einen Direkten Link zu den Jeweiligen Autos im Handel.
